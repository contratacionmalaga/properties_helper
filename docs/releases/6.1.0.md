# Properties Helper 6.1.0

Esta versión actualiza las dependencias y herramientas comunes mediante `jarios-parent:1.0.15`, incorpora las actualizaciones de GitHub Actions y renueva por completo el README. No modifica la API pública ni el comportamiento del código Java respecto a 6.0.5.

## Versiones del proyecto

| Componente | Versión anterior | Nueva versión |
|---|---|---|
| Properties Helper | 6.0.5 | **6.1.0** |
| Jarios Parent | 1.0.13 | **1.0.15** |

## Dependencias actualizadas

Las versiones se heredan del parent, sin duplicar su gestión en el POM del proyecto.

| Dependencia | Anterior | Nueva | Ámbito |
|---|---|---|---|
| Jackson Databind | 2.22.2 | **2.22.3** | Compilación y ejecución |
| Jackson Core | 2.22.2 | **2.22.3** | Transitiva de Jackson Databind |
| SLF4J API | 2.0.18 | **2.0.20** | Compilación y ejecución |
| Lombok | 1.18.46 | **1.18.48** | Compilación (`provided`) |
| Logback Classic y Core | 1.6.3 | **1.6.4** | Pruebas; Core es transitiva de Classic |

JUnit Jupiter **6.1.3**, AssertJ **3.27.7** y Jackson Annotations **2.22** mantienen sus versiones.

El parent también actualiza versiones gestionadas que este proyecto no utiliza directamente: Hibernate, Jsoup, H2, Maven Failsafe y Build Helper, además de las propiedades de Find Security Bugs y UUID. Estas entradas no incorporan nuevas dependencias ni ejecuciones al proyecto. El detalle completo está en la [comparación del parent 1.0.13 → 1.0.15](https://github.com/contratacionmalaga/jarios-parent/compare/v1.0.13...v1.0.15).

## Integración continua

`actions/setup-java` se actualiza de **v5.7.0 a v6.0.1** en los workflows **CI**, **Quality**, **Dependency Check** y **Release Package**. Esta actualización incluye las PR #48 y #49 de Dependabot, integradas antes de preparar la release.

Las demás acciones mantienen sus versiones: `actions/checkout@v7.0.1`, `actions/cache@v6.1.0` y `actions/upload-artifact@v7.0.1`.

## Renovación del README.md

El README se reestructura como documentación de uso y mantenimiento de la biblioteca:

- Ficha técnica de la versión 6.1.0, requisitos y coordenadas Maven.
- Instrucciones de instalación y acceso autenticado a GitHub Packages, incluido el parent.
- Ejemplo completo de inicio rápido con validación y exportación enmascarada.
- Documentación de las instancias independientes y del singleton compartido.
- Explicación de la precedencia fichero → entorno → propiedades de la JVM.
- Aclaración de la codificación ISO-8859-1 y los escapes Unicode de los ficheros `.properties`.
- Documentación de la validación de claves y de sus diferencias con la resolución alternativa.
- Explicación de las modificaciones en memoria y de la recarga desde disco.
- Alcance del enmascaramiento, exportación JSON y copias defensivas.
- Tabla de referencia de la API e inventario de dependencias.
- Comandos de compilación, pruebas, calidad y análisis de vulnerabilidades.
- Descripción del umbral de cobertura de instrucciones del 70 %.
- Corrección del proceso de publicación: el workflow se activa por envío de tags `v*` o ejecución manual.
- Enlace a estas notas de versión y directrices de mantenimiento.

Las funcionalidades descritas ya existían; su documentación ampliada no implica cambios de comportamiento en esta entrega.

## Validación de la versión

- `./mvnw -B -ntp -Pquality clean verify`: correcto; **14 pruebas**, sin fallos, errores ni pruebas omitidas.
- Spotless: formato correcto; Checkstyle: **0 infracciones**; SpotBugs: **0 incidencias**.
- JaCoCo: umbral del **70 % de cobertura de instrucciones** superado.
- `./mvnw -B -ntp org.owasp:dependency-check-maven:check`: correcto con actualización de la base NVD y umbral CVSS **8.0**. OSS Index está desactivado por la configuración del parent.
- Árbol de dependencias resuelto y contrastado con el inventario del README.

Los comandos se ejecutaron mediante `mvnw.cmd` en Windows. La comprobación de vulnerabilidades corresponde a los datos disponibles en el momento del análisis.
